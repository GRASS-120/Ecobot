# Верстак и крафт

Не все ресурсы можно добыть и использовать сразу — для этого существует верстак и крафт. Верстак — это постройка, необходимая для создания инструментов, построек и других предметов. Изначально в нём есть несколько рецептов для крафта, но со временем их количество значительно возрастёт.
