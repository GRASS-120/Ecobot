# Визуальное программирование

В Ecobot используется интуитивная система визуального программирования, которая позволяет создавать программы без написания текстового кода. Вы будете собирать алгоритмы из готовых блоков, как конструктор!

## Что такое визуальное программирование?

**Визуальное программирование** — это способ создания программ путем перетаскивания и соединения графических блоков, а не написания текста.

Представьте, что вы собираете конструктор LEGO — каждый блок имеет определенную функцию, а вместе они создают сложные механизмы.

Окно программирования робота, можно разделить на две части палитра блоков и рабочая область.

**Палитра блоков** — содержит все доступные команды, разбитые по категориям.

**Рабочая область** — место, где вы собираете свою программу из блоков.

## Из чего состоит блок?

Каждый блок в визуальном программировании Ecobot имеет специальные разъемы (слоты), которые определяют, как блоки соединяются и взаимодействуют между собой. Всего существует два слота: треугольный и круглый.

**Треугольные слоты** задают порядок выполнения программы. Они показывают, какая команда выполняется после какой.

**Как работают:**
- Программа выполняется слева на право
- Каждый блок передает управление следующему через треугольный слот
- Если слот не соединен — программа останавливается

**Круглые слоты** передают информацию в блоки. Они определяют, с какими объектами работает программа.

**Что передается через круглые слоты:**
- Типы ресурсов (`железо`, `дерево`, `вода`)
- Объекты (`склад`, `завод`, `дерево`)
- Направления (`вперед`, `налево`, `направо`)
- Количества (`5`, `10`, `100`)

## Как создавать программу?

1. **Перетащите блок** - из палитры в рабочую область.
2. **Соедините блоки с помощью линий** - для этого надо соеденить правую часть одного блока с левой частью другого блока.
3. **Настройте параметры** — некоторые блокы имеют настраиваемые значения.
4. **Протестируйте** — запустите программу и наблюдайте за результатом.
