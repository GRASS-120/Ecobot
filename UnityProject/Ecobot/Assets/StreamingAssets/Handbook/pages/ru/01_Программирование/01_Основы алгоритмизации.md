# Основы алгоритмизации

Прежде чем начать программировать роботов, давайте разберемся с базовыми понятиями, которые помогут вам понимать логику их работы.

## Что такое алгоритм?

**Алгоритм** — это последовательность четких шагов (инструкций), которые необходимо выполнить для достижения определенной цели.

**Простой пример из жизни:**

1. Взять зубную пасту
2. Открыть тюбик
3. Выдавить пасту на щетку
4. Почистить зубы
5. Прополоскать рот

## Базовые операторы

### Последовательность

Команды выполняются одна за другой, по порядку.

**Пример:** 
1. Открыть дверь
2. Войти в комнату
3. Закрыть дверь

### Условие (ЕСЛИ-ТО)
Выполняются разные действия в зависимости от ситуации.

**Пример:**

ЕСЛИ на улице дождь ТО

взять зонт

ИНАЧЕ

надеть кепку


**Еще пример:**

ЕСЛИ в холодильнике есть молокоТО

налить стакан молока

ИНАЧЕ

купить молоко

### Циклы (повторение)

#### Цикл ПОКА
Повторять действие, пока условие верно.

**Пример:**

ПОКА тарелка не пустая

есть ложку супа

#### Цикл ДЛЯ
Повторить действие определенное количество раз.

**Пример:**

ДЛЯ каждого гостя в списке

поздороваться за руку

## Переменные

**Переменная** — как коробка с названием, где можно хранить информацию.

**Примеры:**

количество_яблок = 5

имя_друга = "Саша"

температура_за_окном = -10
